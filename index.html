Gym Planner

Besturing
  • Pijltjes / WASD — lopen (Shift = sneller)
  • Twee vingers op touchpad — rondkijken
  • Klik op een object — selecteren
  • Slepen — object verplaatsen
  • R — geselecteerd object draaien
  • Delete — object naar opslag
  • T — wissel van zaal
  • Esc — deselecteren / annuleren

Opslag

Leeg — druk op Delete bij een geselecteerd object.
